# nix-compile — Adversarial Review Fixes

## PRIORITY 1 — Critical Correctness

- [x] **FIX-1**: `collectFreeVars` doesn't shadow lambda parameters — over-restrictive generalization
  - File: `lib/NixCompile/Nix/Infer.hs:694`
  - `NAbs _params b -> collectFreeVars b` doesn't subtract bound params
  - Causes false dependency edges in SCC → fewer type vars generalized → spurious inference failures
  - **FIXED**: Now extracts bound names from `Params`, filters them from body FVs, and separately collects FVs from param defaults.

- [x] **FIX-2**: Config path segments unvalidated → JSON injection in emit-config
  - Files: `lib/NixCompile/Bash/Patterns.hs:194`, `lib/NixCompile/Emit/Config.hs:182`
  - `validConfigPath` only checks non-empty; no character restrictions
  - Path segments containing `"` or other special chars break JSON/YAML/TOML output
  - **FIXED**: Added `isSafeConfigChar` restricting segments to `[A-Za-z0-9_-]`.

- [x] **FIX-3**: `findAllNixFiles` no symlink cycle detection → infinite loop
  - File: `app/nix-compile.hs:373-385`
  - No `visited` set; symlink cycle in directory tree hangs forever
  - **FIXED**: Rewrote as worklist algorithm with `Set`-based visited tracking + `canonicalizePath`.

## PRIORITY 2 — Security

  - `import ../../etc/passwd` would be accepted if file exists

- [ ] **FIX-5**: `unsafePerformIO` in test suite

## PRIORITY 3 — Design Flaws

- [x] **FIX-6**: `applyDefaults` makes unjustified type choices
  - File: `lib/NixCompile/Schema/Build.hs:120-121`
  - Analysis: TNumeric is never generated by `factsToConstraints`; this is a dead code path. `TVar -> TString` is appropriate for unresolved bash variables. No code change needed.

- [x] **FIX-7**: `NPlus` generates no type constraint
  - File: `lib/NixCompile/Nix/Infer.hs:493-496`
  - `NPlus` returns fresh variable; `true + 5` type-checks as anything
  - **FIXED**: `NPlus` now unifies both sides and returns the unified type.

- [x] **FIX-8**: `unifyUnion` silently succeeds on multi-element unions
  - File: `lib/NixCompile/Nix/Infer.hs:312-315`
  - `TUnion [TInt, TString]` unifies with anything → defeats union types
  - **FIXED**: Now checks concrete membership for multi-element unions; allows TVars.

- [x] **FIX-9**: `mergeSchemas` / `Map.union` silently drops data
  - Files: `lib/NixCompile/Types.hs:347`, `lib/NixCompile/Schema/Build.hs:63`
  - Analysis: Both entries share `resolveType subst var`, so `envType e1 == envType e2` always. The merge is correct; just had a misleading comment.
  - **FIXED**: Clarified comment.

- [ ] **FIX-10**: `//` in `isStorePath` blocks possibly-valid store paths
  - Files: `lib/NixCompile/Types.hs:272`, `lib/NixCompile/Bash/Patterns.hs:246`
  - Spec only requires blocking `..`; `//` is extra-conservative (safe to keep, low priority)
